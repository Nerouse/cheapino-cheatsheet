# cheapino-cheatsheet

Cheapino v2 interactive keymap reference — a web app for browsing keyboard profiles, layouts, and firmware.

Built with vanilla HTML, CSS, and JavaScript. No frameworks, no build step.

## Pages

- **Keymap** — visual keyboard layout with layer switching
- **Configs** — browse profiles and compare layouts
- **Files** — file browser for firmware and VIL configs
- **Docs** — layer system documentation
- **Repo** — GitHub link

## Keyboard Profiles

| File | Description |
|---|---|
| `cheapino-v2-v3.vil` | Standard layout with tap-dance layers |
| `cheapino-vial-mo.vil` | Momentary (MO) based layer switching |
| `cheapino-vial-stock.vil` | Stock/default layout |
| `cheapino-vial-combo.vil` | Combo-based layout |
| `cheapino-vial-layout.vil` | Layout variant |
