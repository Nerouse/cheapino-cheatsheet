LAYER SWAP ENGINE

36-key split keyboard · tap-dance layer toggles · momentary holds

LAYOUT PHILOSOPHY

36-key split. Two left thumbs handle all layer switching. Right: YUIOP/HJKL;/NM,./ plus Shift/Space/Bksp. Left: QWERT/ASDFG/ZXCVB plus Enter, THUMB 1, THUMB 2.

TWO-KEY LAYER SYSTEM

Each thumb toggles a layer on tap, holds momentarily on long press. Only one non-base layer active at any time.

Under 175ms = TG(n) toggle. Over 175ms = MO(n) hold.
