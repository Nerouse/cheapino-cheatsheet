LAYER SWAP ENGINE

36-key split · tap-dance layer toggles · momentary holds

LAYOUT PHILOSOPHY

The Cheapino v2 is a 36-key split keyboard. Two left thumb keys handle all layer switching, leaving other fingers free for typing, mousing, and navigation.

Right half: YUIOP / HJKL; / NM,./ plus Shift, Space, Bksp thumbs. Left half: QWERT / ASDFG / ZXCVB plus Enter, THUMB 1, THUMB 2.

TWO-KEY LAYER SYSTEM

Each thumb key has a toggle mode (tap to enter a layer, tap again to leave) and a hold mode (hold to temporarily access another layer). Only one non-base layer active at any time.

Press under 175ms → TG(n) toggle. Press over 175ms → MO(n) hold.

TOGGLE vs MOMENTARY

  • TG(n) — tap to enter, same tap to leave. For MOUSE and WIN.
  • MO(n) — hold to activate, release to return. For NUMBERS and NAV.
  • TO(n) — go to layer n only, turning off all others. For swapping and return to BASE.

175ms tapping term separates tap from hold.
